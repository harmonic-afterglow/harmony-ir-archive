Harmony IR archive

Logitech's Harmony device and IR data, as captured on 2026-09-02, served as static JSON for Afterglow and anyone else. The source and how this is built: harmonic-afterglow/harmony-ir-archive.

  • api/v1/manifest.json - counts, the capture's checksum, the layout
  • api/v1/manufacturers.json - every manufacturer
  • api/v1/manufacturers/<slug>.json - a manufacturer's devices
  • api/v1/devices/<id % 1024, 3 hex digits>.json.gz - devices, by id
  • api/v1/codesets/<first 3 hex digits>.json.gz - command sets, by hash
  • api/v1/protocols.json - all 684 IR protocols
